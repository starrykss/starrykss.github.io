# Technology icons

The homepage serves these SVGs locally so Tooling badges and Tech Stack cards
share the same logos without relying on third-party icon CDNs at runtime.
Original SVG fills and gradients are preserved.

- Most icons: [Devicon](https://github.com/devicons/devicon), pinned to commit
  `7330accdbc47e2dc0c19789a48533c4a3c50fe58`. Each file comes from
  `icons/<name>/<name>-original.svg`, except `vite.svg`, which uses the build-tool
  logo from `icons/vitejs/vitejs-original.svg`. MIT license: `DEVICON-LICENSE.txt`.
- `reactquery.svg`: [TanStack Query](https://github.com/TanStack/query),
  `media/emblem-light.svg` at commit `c9f91d1dbe1a2f3ed1cb009e0f479290bbb7ce91`.
  MIT license: `TANSTACK-LICENSE.txt`.
- `render.svg`: [Simple Icons](https://github.com/simple-icons/simple-icons),
  `icons/render.svg` at commit `1089fb7d2bf0e323f834c205ab76265005a6d5e8`.
- `openai.svg`: Simple Icons `icons/openai.svg` from release `14.15.0`.
  The OpenAI Blossom mark represents Codex.

Simple Icons assets are distributed under CC0 1.0. Brand names and logos remain
the property of their respective owners.
